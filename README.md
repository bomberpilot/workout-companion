# Workout Companion

A private group accountability app built around showing up, rather than measuring athletic performance.

The existing app uses Expo, React Native, Firebase Authentication and Firestore. Start with [ship readiness](docs/SHIP_READINESS.md) for verified source findings, release blockers and the execution order. See [development](docs/DEVELOPMENT.md) for installation and checks, and [device smoke tests](docs/SMOKE_TEST.md) for the golden user path.

This repository is not yet ready for store submission. Passing TypeScript, backend unit tests and Metro export checks does not establish native build, device, security or store acceptance.
